===============================================================================
  TETRIS  (1988, Spectrum HoloByte / IBM CGA 판 프로그램 ENG AN JIO)
  C 변환판 + VGA 256색 리마스터                    VGA REMASTER BY IN-HAK MIN
===============================================================================

[들어 있는 파일]
  TETVGA.EXE    VGA 256색 리마스터 판 + 애드립 배경음악
  TETRIS.EXE    원본과 똑같이 동작하는 판 (원본 CTETRIS.EXE 를 역어셈블해 C 로 옮김)
                화면도 원본 그대로 CGA 네 색 (검정/청록/빨강/흰색)
  TTVGA.DAT     256색 그림 묶음        - TETVGA.EXE 에 필요
  SOUND.DAT     배경음악 묶음          - TETVGA.EXE 에 필요 (애드립/사운드블라스터)
  CWSDPMI.EXE   32비트 도스 실행 도우미 - 두 판 모두 필요
  BKGR0..BKGR9  판마다의 배경 그림     ) 원판 자료 그대로.
  SLC           판/높이 고르는 화면    ) 게임이 읽으므로
  TETRIS.TTL    제목 그림              ) 같은 폴더에 있어야 한다
  HIGH          점수표 (놀면 갱신된다)

  모두 한 폴더에 두고 실행한다.

[실행]
  도스 또는 DOSBox 에서
      TETVGA        256색 + 음악 판
      TETRIS        원본 그대로의 판
  VGA 그래픽 카드가 필요하다 (DOSBox 기본 설정이면 된다).
  배경음악은 애드립/사운드블라스터가 있을 때만 난다 (없으면 조용히 넘어간다).
  시작할 때 조이스틱을 쓸지 묻는다 - 자판으로 하려면 N 을 누른다.

  빠르기는 4.77MHz IBM PC 에 맞춰 두었다 (원판이 기계 속도를 재어 맞추던 것을
  그대로 흉내 낸다).  조각은 여섯 번째 그림마다 한 줄 내려간다.
  기다리지 않고 최고 속도로 돌리려면  SET TTFAST=1  을 먼저 해 둔다.

[조작]
  왼쪽/오른쪽 화살표, 또는 J / L      옆으로 옮기기
  5 (숫자판) / K / 엔터               돌리기
  스페이스, 2 (숫자판), 쉼표          떨어뜨리기
  8 (숫자판) / I                      빨리 내리기
  1 (숫자판) / M                      다음 조각 보이기 / 감추기
  F1                                  도움말 (조작 키)
  F2                                  통계 (조각 종류마다 몇 개 나왔나)
  F3                                  지금 판 번호
  F4                                  이 판 배경 설명
  S                                   소리 켜고 끄기 (배경음악도 함께 멈춘다)
  P                                   잠깐 멈춤 (다시 P)
  ESC                                 통계 화면 (급한 일이 생겼을 때 그 화면)
  Q                                   그만두기

  제목 -> 만든이 -> 판/높이 고르기 순서로 넘어간다.  판 고르기 화면에서
  화살표로 고르고 엔터를 누르면 시작한다.

[VGA 256색 판]
  게임 속은 원판 그대로다.  화면만 다시 칠했다.
    - 배경 열두 장을 256색으로 다시 칠했다.  원판이 네 색으로 그늘을 내려고 쓰던
      점 뿌리기(디더)를 풀어 고른 밝기를 얻고, 그림마다 정한 규칙(하늘 그러데이션,
      벽돌, 눈, 나뭇잎 ...)으로 색을 입혔다.
    - 조각 일곱 가지는 테두리와 빛, 그늘, 반짝이가 있는 보석처럼 그렸다.
    - 점수와 글자는 바탕 밝기에 따라 금빛이나 짙은 색으로 골라 찍는다.

[소리]
  효과음은 원판 그대로 PC 스피커다 (높이와 길이까지 같다).
  배경음악은 같은 회사가 1992 년에 낸 Tetris Classic (음악 Paul Mogg) 의
  OPL3 음악을 화면마다 얹은 것이다.  판이 오르면 그 판의 곡으로 바뀐다.

[어떻게 만들었나]
  원판 CTETRIS.EXE (MS EXEPACK 으로 눌린 8086 어셈블리 9 KB) 를 풀어 흐름을 따라
  함수 80 개를 찾고 기계적으로 C 로 옮겼다.  옮긴 C 와 원판을 같은 자판 입력으로
  나란히 돌려, 인터럽트마다 레지스터를, 키를 읽을 때마다 메모리와 화면을 맞춰 본다.
  마구잡이 입력을 포함한 다섯 가지 시나리오가 한 줄도 다르지 않다.

  원판과 다른 점은 화면(256색)과 배경음악뿐이고, 게임 규칙·점수·조각 순서·빠르기는
  원판과 똑같다.
